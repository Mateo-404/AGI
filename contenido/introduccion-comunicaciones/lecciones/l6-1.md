## Introducción

El modelo TCP/IP es el modelo de 4 capas usado en Internet. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## Las cuatro capas del modelo TCP/IP

1. **Acceso a la red**: Ethernet, Wi-Fi.
2. **Interred**: IP.
3. **Transporte**: TCP, UDP.
4. **Aplicación**: HTTP, FTP, DNS, etc. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## Protocolo IP

IP direcciona y enruta paquetes entre redes. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## Subnetting y CIDR

División de una red en subredes y notación de prefijo de red. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## Protocolos de transporte

- **TCP**: confiable y orientado a conexión.
- **UDP**: no confiable y sin conexión. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## Protocolos de aplicación

HTTP, FTP, DNS, SMTP, etc. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## ARP y resolución de direcciones

ARP resuelve direcciones IP a direcciones MAC. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## ICMP y diagnóstico

ICMP se usa en diagnóstico (ping). {a Apuntes de Introducción a las comunicaciones · Unidad 6}

## Comparación OSI vs. TCP/IP

El modelo OSI tiene 7 capas; TCP/IP tiene 4 y es el usado en Internet. {a Apuntes de Introducción a las comunicaciones · Unidad 6}

:::sintesis
- TCP/IP tiene 4 capas: acceso a la red, interred, transporte y aplicación.
- IP direcciona y enruta; TCP es confiable, UDP no.
- ARP resuelve IP a MAC; ICMP diagnostica. {a Apuntes de Introducción a las comunicaciones · Unidad 6}
:::
