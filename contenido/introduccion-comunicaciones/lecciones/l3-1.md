## Introducción

El modelo OSI es un modelo de referencia de 7 capas para la comunicación en redes. {a Apuntes de Introducción a las comunicaciones · Unidad 3}

## Las siete capas del modelo OSI

1. **Física**: transmisión de bits por el medio.
2. **Enlace de datos**: tramas, MAC, control de acceso al medio.
3. **Red**: direccionamiento lógico y enrutamiento.
4. **Transporte**: extremo a extremo, TCP/UDP.
5. **Sesión**: gestión de sesiones.
6. **Presentación**: formato y cifrado.
7. **Aplicación**: servicios al usuario. {a Apuntes de Introducción a las comunicaciones · Unidad 3}

## Encapsulamiento

Proceso de agregar encabezados (y trailers) a los datos al descender por las capas. {a Apuntes de Introducción a las comunicaciones · Unidad 3}

## Comunicación entre capas

Cada capa se comunica con su par en el otro extremo. {a Apuntes de Introducción a las comunicaciones · Unidad 3}

## Dispositivos por capa

- Capa 1: hubs, repetidores.
- Capa 2: switches, bridges.
- Capa 3: routers. {a Apuntes de Introducción a las comunicaciones · Unidad 3}

## Resumen de funciones por capa

Cada capa tiene funciones específicas que se resumen en el apunte. {a Apuntes de Introducción a las comunicaciones · Unidad 3}

:::sintesis
- El modelo OSI tiene 7 capas, de física a aplicación.
- El encapsulamiento agrega encabezados al descender.
- Los dispositivos se asocian a capas (hub L1, switch L2, router L3). {a Apuntes de Introducción a las comunicaciones · Unidad 3}
:::
