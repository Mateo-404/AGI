El **análisis marginal** evalúa el **costo y beneficio incremental** de una decisión (siguiente unidad, siguiente cliente, siguiente proyecto). La **relación costo-volumen-utilidad (CVU)** modela cómo cambian los costos, el volumen y el precio para afectar la utilidad. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

## Supuestos básicos del modelo CVU

1. **Linealidad**: costos fijos = ctes en rango relevante; costos variables = ctes por unidad.
2. **Un solo producto** (o mix de ventas constante).
3. **Inventarios constantes** (producción = ventas) o costeo variable.
4. **Precio de venta constante** (sin descuentos por volumen). {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

## Contribución Marginal (CMg)

Es lo que **cada unidad vendida aporta** para cubrir costos fijos y generar utilidad. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

**CMg unitario** = Precio de venta unitario (PV) − Costo variable unitario (CVu)
**CMg total** = CMg unitario × Unidades vendidas = Ingresos − Costos variables totales {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

> La CMg primero paga los **costos fijos**; lo que sobra es **utilidad**. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

```mermaid Flujo de la Contribución Marginal
flowchart LR
  Ventas[Ingresos<br/>PV × Q] --> CV[Costos Variables<br/>CVu × Q]
  CV --> CMg[Contribución Marginal<br/>CMg = PV - CVu]
  CMg --> CF[Costos Fijos]
  CF --> Util[Utilidad Operativa]```

## Punto de Equilibrio (PE)

Volumen donde **Ingresos = Costos Totales** (Utilidad = 0). {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

**En unidades**: `PEu = CF / (PV - CVu) = CF / CMg_unitario`
**En pesos**: `PE$ = CF / (1 - CVu/PV) = CF / Ratio_CMg` {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

> **Ratio CMg** = CMg / PV = (PV - CVu) / PV = 1 - (CVu/PV) {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

:::ejemplo Cálculo de PE
PV = $1.000/unidad; CVu = $600/unidad; CF = $2.000.000/mes
- CMg unitario = $1.000 - $600 = $400
- Ratio CMg = $400 / $1.000 = 40%
- **PEu** = $2.000.000 / $400 = **5.000 unidades**
- **PE$** = $2.000.000 / 0,40 = **$5.000.000** {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

Verificación: 5.000 × $1.000 = $5.000.000 ingresos; 5.000 × $600 = $3.000.000 CV; CMg = $2.000.000; CF = $2.000.000; Utilidad = 0. ✓ {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}
:::

## Margen de Seguridad (MS)

Mide **cuánto pueden caer las ventas** antes de llegar al punto de equilibrio. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

**En unidades**: `MSu = Ventas reales (u) - PEu`
**En pesos**: `MS$ = Ventas reales ($) - PE$`
**Ratio MS**: `MS% = MSu / Ventas reales (u)` (o `MS$ / Ventas reales ($)`) {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

:::ejemplo Margen de Seguridad
Ventas reales = 8.000 unidades; PEu = 5.000 unidades
- **MSu** = 8.000 - 5.000 = **3.000 unidades** (37,5% de margen)
- Ventas pueden caer 37,5% antes de perder plata. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}
:::

## Apalancamiento Operativo (GAO)

Mide la **sensibilidad de la utilidad** ante cambios en las ventas. A mayor proporción de costos fijos, mayor apalancamiento. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

**GAO** = Contribución Marginal / Utilidad Operativa = 1 + (CF / Utilidad) {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

> Si GAO = 2, un 10% más de ventas → 20% más de utilidad. Un 10% menos de ventas → 20% menos de utilidad. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

:::ejemplo GAO
Del ejemplo anterior: CMg total (8.000 u) = 8.000 × $400 = $3.200.000; Utilidad = $1.200.000
- **GAO** = $3.200.000 / $1.200.000 = **2,67**
- Si ventas suben 10% (8.800 u): CMg = $3.520.000; Utilidad = $1.520.000 (+26,7% ≈ 2,67 × 10%)
- Si ventas bajan 10% (7.200 u): CMg = $2.880.000; Utilidad = $880.000 (-26,7%) {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}
:::

## Decisiones con análisis marginal

El análisis marginal compara **costos y beneficios incrementales** de cada alternativa: {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

| Decisión | Costos relevantes | Costos irrelevantes (hundidos) |
|---|---|---|
| **Aceptar pedido especial** | CVu del pedido + costos incrementales específicos | CF, costos ya incurridos |
| **Fabricar o comprar (Make or Buy)** | CVu fabricar vs. precio compra + costos de transacción | CF, equipos ya comprados |
| **Eliminar producto/segmento** | Costos que SE EVITAN al eliminar | CF que NO se eliminan (se redistribuyen) |
| **Utilizar capacidad ociosa** | Solo costos variables incrementales | CF, depreciación de equipos ociosos | {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}

:::clave Regla de oro del análisis marginal
**Solo importan los costos futuros que DIFEREN entre alternativas**. Lo que ya pasó (hundido) o lo que es igual en todas las opciones, no decide. {d}
:::

:::sintesis
- CMg = PV - CVu. Primero paga CF; lo que sobra es utilidad.
- PEu = CF / CMg_unitario; PE$ = CF / Ratio_CMg.
- MS = qué tan lejos estás del PE (colchón de seguridad).
- GAO = CMg / Utilidad = sensibilidad de utilidad a ventas.
- Decisiones marginales: solo costos incrementales que difieren entre alternativas. {a Apuntes de Cálculo de costos y rendimientos · Unidad 4}
:::
