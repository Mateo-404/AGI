**Implementación** es la fase donde se traduce el diseño a código ejecutable y bases de datos, con selección de herramientas (IDEs, lenguajes, DBMS) e implementación ágil en sprints. El código limpio (Clean Code) facilita el mantenimiento. {a Apuntes de Ingeniería de Software · Unidad 4}

## Pruebas (Testing)

Las pruebas detectan y corregir errores antes de que lleguen al usuario final. {a Apuntes de Ingeniería de Software · Unidad 4}

- **Verificación**: «¿construimos el producto correctamente?» (cumple el diseño).
- **Validación**: «¿construimos el producto correcto?» (satisface la necesidad). {a Apuntes de Ingeniería de Software · Unidad 4}

## Niveles de prueba

- **Unidad**: cada componente aislado.
- **Integración**: interfaces entre componentes ensamblados.
- **Sistema**: el sistema completo en su entorno.
- **Aceptación**: validada por el cliente para autorizar el despliegue. {a Apuntes de Ingeniería de Software · Unidad 4}

## Tipos de prueba por caja

- **Caja blanca**: visibilidad total del código.
- **Caja negra**: el componente se trata como caja opaca.
- **Caja gris**: enfoque híbrido. {a Apuntes de Ingeniería de Software · Unidad 4}

## Técnicas de casos

Partición de equivalencia, análisis de valores límite y cobertura. {a Apuntes de Ingeniería de Software · Unidad 4}

## Pruebas alfa y beta

- **Alfa**: versiones tempranas a usuarios internos.
- **Beta**: liberación a usuarios externos antes del lanzamiento masivo. {a Apuntes de Ingeniería de Software · Unidad 4}

## Despliegue

Puesta en marcha del sistema en producción, con instalación, configuración y capacitación. {a Apuntes de Ingeniería de Software · Unidad 4}

## Tipos de mantenimiento

- **Correctivo**: corrección de defectos.
- **Adaptativo**: adaptación a cambios del entorno.
- **Perfectivo**: mejoras y nuevas funcionalidades.
- **Preventivo**: reducción de degradación futura. {a Apuntes de Ingeniería de Software · Unidad 4}

## Modelos de ciclo de vida

Cascada, prototipos, iterativo, espiral, evolutivo, ágil. {a Apuntes de Ingeniería de Software · Unidad 4}

:::sintesis
- Verificación comprueba que construimos el producto correctamente.
- Validación comprueba que construimos el producto correcto.
- Hay cuatro niveles de prueba y tres tipos por caja.
- Los tipos de mantenimiento son correctivo, adaptativo, perfectivo y preventivo. {a Apuntes de Ingeniería de Software · Unidad 4}
:::
