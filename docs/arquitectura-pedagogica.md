# Arquitectura pedagógica

## 1. Principios
- **Fidelidad a la fuente:** cada bloque de contenido lleva su origen: `cuaderno` (con capítulo y página), `didactico` (explicación nuestra, no atribuida a la cátedra) o `ampliacion` (fuente externa verificada, con fecha).
- **Recuperación activa antes que relectura:** cada lección cierra con preguntas que obligan a razonar y tarjetas de memoria.
- **Práctica espaciada:** repaso sugerido a +1, +3, +7, +14 y +30 días, calculado localmente.
- **Dominio ≠ acierto:** un tema se considera *consolidado* solo con ≥3 aciertos, en ≥2 días distintos, de los cuales al menos uno sin pista (respuesta corta o confianza alta). El quiz descuenta el azar (acierto − error/(opciones−1)).
- **Etiquetado de práctica:** todo ejercicio es *material de práctica creado para este curso*, no una evaluación oficial ni preguntas de la cátedra.

## 2. Secuencia y dependencias

```
U1 Concepto ─► U2 Evolución, mix y consumidor ─► U3 Plan, segmentación, journey ─┬► U4 SEO/SEM
                                                                                  ├► U5 Redes sociales
                                                                                  ├► U6 E-commerce
                                                                                  └► U7 E-mail
                                                                                        │
                                                         L8 Integración (TP + escalabilidad digital)
```

Dependencias conceptuales clave: valor/necesidad (l1-2) → segmentación (l3-3) → posicionamiento → 4P (l2-3…6) → comunicación; consumidor (l2-7/8) → journey/embudo (l3-4) → email (l7-1), contenidos (l5-1), SEO/SEM (l4); objetivos SMART (l3-6) → métricas (l4-3, l7-2); e-commerce (l6) requiere plaza (l2-5) y UX/SEO.

## 4. Estructura de cada lección
Objetivos → conocimientos previos (enlaces) → explicación estructurada en bloques → conceptos clave → ejemplo(s) paso a paso → diagrama explorable → comparación de conceptos confundibles → ejercicios de aplicación → preguntas de recuperación → síntesis y conexiones → referencias al material original. Las secciones sin valor para el tema se omiten.

## 5. Actividades y evaluación
| Mecanismo | Descripción |
|---|---|
| Preguntas de opción múltiple | explicación de **cada** alternativa; puntaje corregido por azar |
| Respuesta corta con autoevaluación | se muestra respuesta modelo y criterios; el estudiante marca cumplidos |
| Asociación y clasificación | arrastre/selección por categoría con retroalimentación |
| Casos con decisiones | decisión → consecuencia → justificación |
| Simuladores | embudo; calculadora de métricas publicitarias; punto de equilibrio de precio |
| Tarjetas de memoria | respuesta revelable, autocalificación y programación espaciada |
| Quiz por lección, por unidad y simulacro integrador | acumulativo; muestreo ponderado hacia lo no dominado |
| Repaso de errores | cola de preguntas falladas con recomendaciones de lección |
