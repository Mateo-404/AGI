El **diseño de software** define la arquitectura y los detalles del sistema. {a Apuntes de Ingeniería de Software · Unidad 3}

## Paradigmas de programación

Forma preestablecida de construir un programa: imperativo (secuencia de instrucciones) y declarativo (se declara qué se quiere obtener). {a Apuntes de Ingeniería de Software · Unidad 3}

## Modelado estructural: Diagramas de Clases (UML)

Muestra la estructura estática del sistema: clases, atributos, métodos y relaciones. {a Apuntes de Ingeniería de Software · Unidad 3}

## Modelado de comportamiento: Diagramas de Casos de Uso

Muestra la interacción entre actores y el sistema. {a Apuntes de Ingeniería de Software · Unidad 3}

## UML

UML (Unified Modeling Language) es el lenguaje de modelado para visualizar, especificar y documentar sistemas. {a Apuntes de Ingeniería de Software · Unidad 3}

:::sintesis
- El diseño define la arquitectura y los detalles.
- Los paradigmas se dividen en imperativo y declarativo.
- Los diagramas de clases muestran la estructura estática.
- Los diagramas de casos de uso muestran la interacción actor-sistema. {a Apuntes de Ingeniería de Software · Unidad 3}
:::
