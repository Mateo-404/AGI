# Tema 5 — Artículos A/An y There is / There are

## 1. Artículos indefinidos A y AN (un / una)

Se usan en singular para hablar de algo no específico. La elección depende del sonido con el que inicia la palabra siguiente, no necesariamente de la letra escrita.

- A → cuando la siguiente palabra comienza con sonido de consonante.
- AN → cuando comienza con sonido de vocal.

Ejemplos:

- Un carro → A car (sonido consonante).
- Una manzana → An apple (sonido vocal).
- Un perro → A dog.
- Un hospital → A hospital (la "H" suena como "J", es consonante).
- Una naranja → An orange.
- Una hora → An hour (la "H" es muda, comienza con sonido vocal).

## 2. There is / There are ("hay")

- THERE IS → se utiliza para singular (una sola cosa).
- THERE ARE → se utiliza para plural (dos o más cosas).

### Forma afirmativa

- Hay un perro. → There is a dog. / There's a dog.
- Hay dos perros. → There are two dogs.

### Forma negativa

- No hay un perro. → There is not a dog. / There isn't a dog.

### Forma interrogativa

Para preguntar se mueve el verbo TO BE al principio de la oración.

- ¿Hay un perro? → Is there a dog?
- ¿Hay un perro en tu casa? → Is there a dog in your house?
- ¿Hay dos perros? → Are there two dogs?
- ¿Hay dos perros en tu casa? → Are there two dogs in your house?

## 3. Ejercicios

1. Hay una naranja en la cocina. → There is an orange in the kitchen.
2. ¿Hay un hospital cerca? → Is there a hospital near?
3. No hay dos carros en el garaje. → There aren't two cars in the garage.
4. Hay una hora para el examen. → There is an hour for the exam.
5. ¿Hay una manzana sobre la mesa? → Is there an apple on the table?
