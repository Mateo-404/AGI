# Tema 4 — Modales de obligación y consejo

## 1. HAVE TO / DON'T HAVE TO (obligación general, reglas externas)

- Uso: reglas en el trabajo, la universidad, las leyes; obligación impuesta externamente.
- Estructura: subject + have to / has to + infinitivo.
  - I / You / We / They → have to.
  - She / He / It → has to.
- DON'T HAVE TO: no hay obligación, es opcional.
  - I / You / We / They → don't have to.
  - She / He / It → doesn't have to.
- Preguntas: Do I have to buy new supplies? / What time does she have to participate in a meeting?

## 2. MUST / MUSTN'T (obligación personal + prohibición)

- MUST: obligación que el hablante mismo impone (personal / moral). Misma forma para todos los sujetos: subject + must + infinitivo.
- MUSTN'T: algo está prohibido, no hacerlo.
- MUST vs HAVE TO: HAVE TO = obligación general / externa; MUST = obligación personal / interna.
- MUSTN'T vs DON'T HAVE TO: mustn't go = prohibido (no puedes ir); don't have to go = no necesario (puedes ir si quieres).

## 3. SHOULD / SHOULDN'T (consejos y recomendaciones)

- Uso: dar consejo o expresar lo que se cree correcto hacer.
- Estructura: subject + should / shouldn't + infinitivo (igual para todos los sujetos).

## 4. Resumen de modales

| Modal | Significado |
|---|---|
| have to | obligación externa / general, necesario |
| don't have to | no obligatorio, opcional |
| must | obligación personal / interna, necesario |
| mustn't | prohibición, no permitido |
| should | consejo / recomendación |
| shouldn't | consejo negativo |
