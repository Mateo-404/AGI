Un **sistema** es un conjunto de elementos interrelacionados que forman un todo con un propósito. Un **sistema de información (SI)** recupera y procesa información para una organización, con recursos humanos, datos, actividades e informáticos. El SI es más amplio que el sistema informático. {a Apuntes de Ingeniería de Software · Unidad 1}

## Dominios de aplicación del software

El software se aplica en salud, finanzas, educación, industria, entretenimiento, gobierno, etc. {a Apuntes de Ingeniería de Software · Unidad 1}

## Ingeniería de Software (IS)

La IS es la aplicación de un enfoque sistemático, disciplinado y cuantificable al desarrollo, operación y mantenimiento del software. {a Apuntes de Ingeniería de Software · Unidad 1}

## Capas de la IS

- **Calidad**: base cultural de mejora continua.
- **Proceso**: marco de trabajo con hitos y control.
- **Métodos**: cómo construir técnicamente el software.
- **Herramientas**: soporte automatizado (CASE). {a Apuntes de Ingeniería de Software · Unidad 1}

## Disciplinas de la IS

- **Técnicas**: requerimientos, análisis, diseño, implementación, prueba, despliegue.
- **De gestión**: planificación, monitoreo y control.
- **De soporte**: configuración, calidad, métricas. {a Apuntes de Ingeniería de Software · Unidad 1}
